# Dataset and publication notes / نکات انتشار

The `Dataset/` directory contains 41 English text documents provided with the original course project. The authorship, license, and redistribution permission for these texts were **not independently verified**.

Before publishing a public repository, confirm that you have permission to share the documents. If permission is unclear, consider making the repository private, documenting the dataset's source, or replacing the text files with properly licensed documents. Be aware that the precomputed inverted index and weights are derived from the same documents.

The original project source and stored index files are preserved. No open-source license has been selected automatically, because that decision belongs to the project owner and the code/data may have different rights.

پوشه `Dataset/` شامل ۴۱ سند انگلیسی است که همراه پروژه اولیه بوده‌اند. منبع اصلی و مجوز بازنشر آن‌ها به‌صورت مستقل تأیید نشده است. قبل از عمومی‌کردن مخزن، مطمئن شو اجازه انتشار این متن‌ها را داری. در غیر این صورت می‌توانی مخزن را خصوصی نگه داری یا دیتاست را با متن‌هایی که مجوز مناسب دارند جایگزین کنی. فایل‌های ایندکس و وزن‌دهی نیز از همین متن‌ها مشتق شده‌اند.

برای کد یا داده‌ها به‌صورت خودکار فایل `LICENSE` اضافه نشده است؛ انتخاب مجوز باید با تصمیم صاحب پروژه و با توجه به حقوق داده‌ها انجام شود.
